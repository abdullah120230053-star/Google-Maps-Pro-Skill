API Documentation

Create a scrape, follow its progress, and download the results. This reference loads locally without an external documentation viewer.

Base URL: http://localhost:8080. Paths below are relative to this address. Requests with JSON bodies need Content-Type: application/json.

The default local engine has no authentication. Keep the published port on 127.0.0.1. An X-API-Key header only provides protection if you separately configure a proxy that validates it.
No request has been sent. This check only lists jobs; it does not start or delete one.

Job workflow

  1. Send a POST /api/v1/jobs request with your query and location.
  2. Read the lowercase id from the creation response.
  3. Poll GET /api/v1/jobs/{id}, typically every 8–15 seconds.
  4. When Status is ok, download the CSV.

States: pending → working → ok or failed. Run one job at a time. If a status check fails, check the existing job before creating another.

Capitalization matters: create returns id; job objects use ID, Name, Date, Status and Data. Input max_time is seconds, while Data.max_time in responses is stored as nanoseconds.

POST/api/v1/jobs

Create an asynchronous scraping job. Returns 201 and its ID; this does not mean scraping is complete.

Request body

FieldTypeUsage
namestringRequired, nonempty job label.
keywordsstring[]Required, nonempty array. Include the location in each term.
langstringRequired, two-letter language code, such as en or ar.
depthintegerRequired, nonzero scroll depth. Start with 5; larger runs take longer.
max_timeintegerRequired, nonzero job time limit in seconds. Use a positive value such as 600.
lat, lonstringRecommended for location targeting; required in fast mode. Send strings, not numbers.
zoomintegerSend 15 for the example city-level search.
radiusintegerSearch radius in meters; the examples use 10000.
fast_modebooleanUse false for normal data collection. Fast mode returns reduced data.
emailbooleantrue asks the engine to check business websites for emails. Slower; coverage depends on published contacts.
extra_reviewsbooleanOptional extended review collection; increases work and output size.
proxiesstring[] or nullOptional proxy URLs. Keep any proxy credentials out of shared examples and reports.

The examples specify the full recommended body instead of depending on unspecified server defaults.

curl -X POST "http://localhost:8080/api/v1/jobs" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Cairo dentists",
    "keywords": ["dentists in Cairo, Egypt"],
    "lang": "en",
    "lat": "30.0444", "lon": "31.2357",
    "zoom": 15, "radius": 10000, "depth": 5,
    "fast_mode": false, "email": true,
    "max_time": 600
  }'

Example response:

{"id":"00000000-0000-4000-8000-000000000001"}

PowerShell

$body = @{
  name = "Cairo dentists"
  keywords = @("dentists in Cairo, Egypt")
  lang = "en"; lat = "30.0444"; lon = "31.2357"
  zoom = 15; radius = 10000; depth = 5
  fast_mode = $false; email = $true; max_time = 600
} | ConvertTo-Json
$job = Invoke-RestMethod -Method Post -Uri "http://localhost:8080/api/v1/jobs" `
  -ContentType "application/json" -Body $body
$job.id

On Windows, use curl.exe if your shell maps curl to another command.

GET/api/v1/jobs

List stored jobs. Returns 200 and a JSON array (or null when the engine has no initialized job list). This API does not expose pagination parameters.

curl "http://localhost:8080/api/v1/jobs"

Illustrative response; no real business data is shown here:

[
  {
    "ID": "00000000-0000-4000-8000-000000000001",
    "Name": "Cairo dentists",
    "Date": "2026-10-29T10:00:00Z",
    "Status": "working",
    "Data": {
      "keywords": ["dentists in Cairo, Egypt"],
      "lang": "en", "depth": 5,
      "lat": "30.0444", "lon": "31.2357",
      "max_time": 600000000000
    }
  }
]

GET/api/v1/jobs/{id}

Read one job by its UUID. Returns 200 with the same job-object structure as the list response, 404 if absent, or 422 for an invalid ID.

curl "http://localhost:8080/api/v1/jobs/00000000-0000-4000-8000-000000000001"

Use the ID returned by your own create request. The UUID above is an example and is not an existing job.

# PowerShell: read status without starting another scrape
Invoke-RestMethod "http://localhost:8080/api/v1/jobs/$($job.id)" |
  Select-Object ID, Name, Status

GET/api/v1/jobs/{id}/download

Download raw engine results after Status becomes ok. Returns 200, Content-Type: text/csv and an attachment filename. A missing CSV returns 404; malformed IDs return 422.

curl "http://localhost:8080/api/v1/jobs/00000000-0000-4000-8000-000000000001/download" \
  --output results.csv
Invoke-WebRequest "http://localhost:8080/api/v1/jobs/$($job.id)/download" `
  -OutFile "results.csv"

The raw CSV includes engine fields such as title, phone, emails, website, category, address, review_rating, review_count, IDs and coordinates. It does not include the PRO CLI's scoring or enrichment passes.

DELETE/api/v1/jobs/{id}

Delete a selected stored job. Successful deletion returns 200 with an empty body. Invalid IDs return 422; engine-side deletion failures return 500.

Deletion is a data-removal operation, not a documented cancellation API. Do not use it to stop active scraping. Save any needed results first.
curl -X DELETE "http://localhost:8080/api/v1/jobs/00000000-0000-4000-8000-000000000001"

Examples are documentation only; this page never creates or deletes jobs automatically.

Errors & troubleshooting

CodeMeaningNext step
200Successful read, download or deleteCheck the documented body format; delete has no JSON body.
201Job createdPoll its status before downloading.
404Job or result file not foundCheck the UUID and completion status.
405Unsupported HTTP methodUse the method shown above.
422Invalid JSON, missing job fields or malformed UUIDRead the message; check name, keywords, language, depth, max_time and coordinate types.
500Engine/storage failureInspect container logs.
502 / 504Proxy cannot reach the engine or timed outCheck that the engine container is running.

JSON errors use this shape; download errors may be plain text:

{"code":422,"message":"missing max time"}

Check logs with docker compose logs --tail 100. For a failed scraping job, the HTTP status request can still return 200: inspect its Status field. Repeated failures can reflect rate limits, network issues or browser errors; they are not evidence of one specific cause.

Where the PRO features run

This HTTP API manages raw engine jobs. Multi-city campaigns, Arabic/English templates, filters, scoring, social profile discovery, website observations and formatted Excel reports run in the repository's Python CLI:

python scripts/scrape.py --campaign examples/campaign.example.json \
  --out output/campaign.xlsx

See the PRO guide for campaign settings and export semantics. For machine-readable API definitions, download OpenAPI JSON.
